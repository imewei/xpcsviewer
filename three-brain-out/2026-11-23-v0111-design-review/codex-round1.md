NOT READY

The plan covers all seven Stage 4 items. Its layer history can lose edits, the swung Q-map tests request channels absent upstream, and the import, averaging, and fit instructions leave user-visible behavior unresolved.

## Blocking findings

1. **B1 · High · Plan:119,128–130 · Layer state and reset.** A draw at A hidden by an accumulated exclusion at A leaves the combined mask unchanged. If the draw moves to B, undo loses the hidden draw state when history is keyed only on combined pixels. Also, with `max_history=3`, the current trim retains draws 4–6, so three undos reach 5, 4, 4. Reset then restores draw 4 because trimming removed the initial state (`xpcsviewer/simplemask/area_mask.py:383–392,415–439,467–477`). Define a protected reset baseline and exact retention semantics. Compare layer contents for history changes, and test a hidden edit, redo invalidation, and reset after trimming.

2. **B2 · High · Spec:112–116, Plan:187–195 · Swung Q-map goldens.** The pinned `core/qmap.py:126–151` comments out `qx` and `qy`, and computes `q=2*k0*sin(alpha/2)`. Local `xpcsviewer/simplemask/qmap.py:395–439` publishes both components and uses `k0*sin(alpha)` for `q`. At 20° those magnitudes differ by about 1.5%. Compare upstream channels and units, specify independent component goldens from the rotated vectors, and keep the original backend path for zero swing. The five-argument versus seven-argument comparison only checks default forwarding. Capture pre-change zero-swing arrays to verify preservation. Identify the probe as M16 (`parity-audit.md:45`) and state whether swing support is API-only, since the desktop dispatcher passes five arguments (`qmap.py:85–102`).

3. **B3 · High · Spec:95–102, Plan:55–68 · Fixed values lack a desktop source.** The G2 UI supplies bounds and flags (`xpcsviewer/xpcs_viewer.py:4203–4253`). `xpcsviewer/xpcs_file.py:1732–1745` derives starts from arithmetic or geometric means, and the high-performance method omits `p0` in both branches (2080–2095). Specify the actual fixed-value rule and how each caller obtains it. A successful explicit-value test already passes when indexed as `fit_val[0,0,2]`. The proposed `[0,2]` is out of bounds (`fitting/legacy.py:267,296–319`). All three failure placeholders overwrite fixed values (313,436,657). Preserve explicit fixed slots in those paths or explicitly define the failure contract. Assert curve accuracy for the all-free test, since a finite midpoint placeholder also passes the proposed check.

4. **B4 · High · Spec:184–188, Plan:75–87 · Empty averaging still lacks GUI feedback.** The desktop connects only `values` and starts a polling timer (`xpcsviewer/xpcs_viewer.py:3253–3313`). Emitting `finished` alone cannot display an empty-result message. Wire a queued GUI-thread completion handler and finalize state before emitting. Preserve cancellation behavior because the sequential and parallel paths can set `killed` and return with zero accepted (`module/average_toolbox.py:262–267,369–386`). Direct `flist=[]` fails at `model[0]` (51–80). Specify whether construction must accept it. The cleared-model fixture already avoids division by zero (125–127,257–269), so assert terminal signals and no output. Enable INFO capture explicitly because the existing reason is INFO and pytest config uses WARNING (`average_toolbox.py:183–185`, `tests/conftest.py:129–134`).

5. **B5 · High · Spec:85–88,184–185, Plan:93–108 · Import failures bypass the new status message.** The window preflight returns before `load_mask` for missing keys, unreadable files and declined dimensions, and prompts for valid transposes (`xpcsviewer/simplemask/simplemask_window.py:444–512`). Route real invalid fixtures through one status/log path and resolve the existing modal warnings against the spec. Guard rank before swapping axes because scalar/1-D HDF5 datasets raise outside the read handler (`area_mask.py:191–213`). Align the new boolean API with `MaskBase.evaluate -> None` (82). Matching and transposed kernel imports are preservation tests.

6. **B6 · High · Plan:25–26,162–175 · Empty geometry has no defined handling.** The pinned rasterizer marks an inclusive ROI present even when it fills nothing (`core/rasterize.py:74–87`). An off-image inclusive triangle kept zero pixels in the reference environment. A collapsed polygon on integer centres also excluded its endpoint pixels. Specify whether off-image inclusive ROIs count and skip degenerate geometry before rasterizing. Assert the entire output for zero-length and zero-size cases. The proposed shape assertion cannot detect excluded pixels. Define whether clicking Apply with no pending drawings clears the previous layer, since the window always applies the returned array (`simplemask_window.py:340–346`).
