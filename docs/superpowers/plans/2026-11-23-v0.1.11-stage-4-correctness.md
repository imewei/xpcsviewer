# v0.1.11 Stage 4: Correctness Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the seven defects that change which pixels enter an analysis or how a result is reported: ROI masks, mask-import failure, layer replacement, fixed fit parameters, empty averaging jobs, wheel version, and swung transmission Q-maps.

**Architecture:** Port upstream pySimpleMask's vertex rasteriser (`skimage.draw.polygon2mask`) and rasterise pyqtgraph ROIs through their own transform instead of pasting `getArrayRegion` blocks. `MaskAssemble` keeps per-layer arrays so draw and parameter edits replace their own layer. The remaining fixes are small, local edits.

**Tech Stack:** Python 3.12+, NumPy, pyqtgraph/PySide6 (qtpy), h5py, scikit-image (new), pytest (+ pytest-qt), uv, ruff, mypy.

## Review Focus

1. ROI partly or fully outside the image, or zero-size/zero-length: must not crash; pixels outside the image never appear; an empty ROI excludes nothing. (Task 7)
2. Inclusive and exclusive ROIs together, and inclusive-only: keep = not-exclusive AND (inclusive if any). (Task 7)
3. Undo, redo, reset and history trimming after layer replacement: the previous draw layer comes back on undo and `layer_record` never drifts from `mask_record`. (Task 5)
4. Averaging job with every input rejected, or zero input files: reaches a terminal state, no divide-by-zero, no output file. (Task 3)
5. Mask import: missing file, wrong key, wrong shape fail without touching mask or history; a transposed mask is still accepted. A fit with every parameter free and `p0=None` still works. (Tasks 2 and 4)
